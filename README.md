# Keitaro Wrapper

Веб-приложение для создания кампаний в **Keitaro** и управления офферами в их потоках через Admin API.

**Стек:** Python 3.12, FastAPI, Pydantic v2, SQLAlchemy 2, Alembic, PostgreSQL, JavaScript, Docker Compose.

## Возможности

**Создание кампаний**
- Ввод названия, GEO-кода страны и выбор оффера по ID или названию.
- Автоматическое добавление префикса `test_фамилия_` к названию.
- Создание двух потоков: посетители из указанной страны → Google; остальные → выбранный оффер.
- Назначение домена, группы кампаний и источника трафика из настроек или справочников Keitaro.

**Редактор офферов**
- Загрузка потоков через **Fetch streams from KT**.
- Добавление и удаление офферов, восстановление удалённых (**Bring back**).
- Автоматический перерасчёт долей до 100% и закрепление доли (**Pin**).
- Работа с локальным черновиком: **Cancel** отменяет изменения, **Push to KT** публикует их в Keitaro.
- Сохранение удалённых офферов в локальной истории; повторный Fetch учитывает внешние изменения.

В приложении также есть изолированный демо-редактор для проверки распределения офферов без подключения к Keitaro.

## Запуск

**Требуется:** Docker с поддержкой Docker Compose.

1. Создайте файл `.env` на основе `.env.example`:

   ```bash
   cp .env.example .env
   ```

   В Windows PowerShell: `Copy-Item .env.example .env`.

2. Укажите в `.env` параметры подключения:

   ```dotenv
   KEITARO_BASE_URL=https://tlgk.host
   KEITARO_API_KEY=YOUR_ADMIN_API_KEY
   CAMPAIGN_PREFIX=test_ivanov_
   KEITARO_WRITE_ENABLED=true
   ```

   `KEITARO_API_KEY` — ключ **Admin API** Keitaro. `CAMPAIGN_PREFIX` задаёт префикс создаваемых кампаний. Остальные параметры, включая `DATABASE_URL`, можно оставить из `.env.example`.

   Домен, группу и источник можно выбрать в форме создания кампании. При необходимости их ID задаются заранее в `.env` через `CAMPAIGN_DOMAIN_ID`, `CAMPAIGN_GROUP_ID` и `CAMPAIGN_TRAFFIC_SOURCE_ID`.

3. Запустите приложение:

   ```bash
   docker compose up -d --build
   ```

Приложение доступно по адресу **http://127.0.0.1:8000**, документация API — **http://127.0.0.1:8000/docs**.

## Миграции базы данных

Используется **Alembic**. Миграции автоматически применяются при запуске контейнера приложения.

Для ручного применения:

```bash
docker compose exec app alembic upgrade head
```

PostgreSQL хранит локальные данные кампаний, историю и черновики; сами кампании и потоки находятся в Keitaro.

## Работа с приложением

1. В разделе **«Создание кампании»** укажите название, страну и оффер. При необходимости выберите домен, группу и источник.
2. Нажмите **«Создать кампанию»**. Приложение автоматически проверит поля и данные через Keitaro API. Если данные некорректны, ошибки появятся рядом с соответствующими полями. При успешной проверке подтвердите создание.
3. После создания автоматически откроется **«Редактор офферов»**. Загрузите потоки, измените состав офферов и опубликуйте черновик через **Push to KT**.

## Ограничения и безопасность

- Изменение разрешено только для кампаний, созданных этой установкой приложения и зарегистрированных в её базе данных. Чужие кампании не редактируются.
- Удаление кампаний и самих офферов из Keitaro не предусмотрено; **Remove** убирает оффер только из выбранного потока после публикации.
- Интерфейс предназначен для **локального запуска** и не содержит отдельной пользовательской авторизации.
- Файл `.env` с API-ключом не включается в Git благодаря `.gitignore`.
